# 交稿前自检表（硬约束）

> **写完没跑这份表 = 这次写作未完成。**
>
> 这不是软建议，是硬约束。任何一项不过 → 回到正文回炉修改 → 再跑一遍 → 循环至全部通过才交付。
>
> 把自检结果抛给用户、由用户决定要不要改 = 把质检外包给用户 = skill 失败。

任何一项不过 → 回去改，不要交稿。

## 硬性计数

| # | 检查项 | 标准 |
|---|--------|------|
| 1 | 全文数字总数 | ≥ 15 个可测量的数字（金额/天数/人数/秒数/距离/温度） |
| 2 | 程度副词 | 0 个（非常/无比/深深/格外/极其/特别/十分） |
| 3 | 情绪形容词直述 | 0 处（"我很难过""我很爱她""我很痛苦"） |
| 4 | 感叹号 / 省略号 / 破折号 / 引号 | 各 0 个 |
| 5 | 排比句 | 0 处 |
| 6 | 反问句 | 0 处 |
| 7 | 比喻 | ≤ 2 处，且必须是名词性比喻 |
| 8 | 「我说好」类顺从句 | ≥ 5 次 |
| 9 | 「我沉默了 / 我没有说 / 我也没有问」类隐瞒句 | ≥ 4 次 |
| 10 | 打破节拍的那一句 | 恰好 1 次，且在全文 80% 位置 |
| 11 | 服务者复调段落 | ≥ 3 段，每 1500 字至少 1 段 |
| 12 | 物件 callback | ≥ 1 组（中段慢写 + 结尾拆开） |
| 13 | 闭环句 | 恰好 3 次，量级逐次放大 |
| 14 | 结尾遗留物清单 | ≥ 5 件，降序排列 |
| 15 | 结尾的直接提问 | 恰好 1 个，且不回答 |
| **16** | **虚构红线（v1.1.0 增补）** | **分档白名单。① 核心数字（司龄 / 通知日期 / 补偿方案）必须在用户输入中可见；② 服务者复调段落中每个出场人物原型（前台 / HR / 保安 / 保洁 / 物业等）必须有用户确认；③ 物件、地点、岗位的具体名称允许在用户确认的边界内自由发挥，但每个通用场景（闸机 / 工位 / 电梯 / 停车场）首次出现时仍需用户授权。白名单为空或越界 → 直接拒绝交付** |

## 结构检查

- [ ] 第一句是不是一个重量/长度/温度/价格？
- [ ] 前两句是不是构成一组量级悬殊的对句？
- [ ] 第一幕结尾有没有把结局交出去？
- [ ] 起源段是不是一个很小、很早、失败了的动作？
- [ ] 高潮段的字数是不是全文最短的实质段落？
- [ ] 高潮有没有用秒数替代情绪？
- [ ] 称呼有没有在关键时刻切换回原名？
- [ ] 结尾有没有从最小量级拉到最大量级？

## 虚构红线方法（第 16 项怎么跑）

**这是 16 项硬指标里唯一一项不靠自检脚本能自动完成的，需要在写作过程中手动维护白名单。**

### 1. 白名单的建立时机

第零关 · 执行硬约束触发后，**进入第 1 步之前**建立白名单。白名单包含三档：

| 档位 | 内容 | 来源 |
|---|---|---|
| **L1 核心数字** | 司龄 / 通知日期 / 补偿方案 / 任何用户原文出现的数字 | **必须**在用户输入中可见 |
| **L2 人物原型** | 服务者复调段落里每个出场人物（前台 / HR / 保安 / 保洁 / 物业等）| **必须**经用户确认 |
| **L3 通用场景** | 闸机 / 工位 / 电梯 / 停车场 / 厨房 / 会议室等场景类名词 | 首次出现时**必须**得到用户授权 |

### 2. 三种合法状态

- **状态 A · 真实素材齐全**（L1 + L2 + L3 均已确认）→ 正常写作，第 16 项直接过。
- **状态 B · 允许虚构**（用户明确说"可以编"）→ L1 仍必须真实，L2 / L3 可在用户边界内自由发挥。每个被虚构的细节必须在草稿区登记为"虚构项"，交稿前删去登记。
- **状态 C · 真实素材不足且不允许虚构**（最常见）→ 第零关闸门不放行，直接回到 ask_user_question 索要真实细节，**不允许进入写作分支**。

### 3. 校验脚本（写作过程中执行）

写作过程中每写一段，反查一次：

1. 把本段所有数字从原文抽取 → 与 L1 比对 → 不在白名单的数字即违规
2. 把本段所有人物名 / 物件名 / 地点名 / 岗位名抽取 → 与 L2 + L3 比对 → 不在白名单即违规
3. 违规 → 立即删除该数字 / 名词 → 用模糊语或留白代替 → 重新校验

### 4. 反例：本次失败的归因

2026-08 用户输入「像孙学一样写一段被裁员的故事，克制一点，别煽情」（17 字，无真实细节）。skill 没有触发第零关闸门，直接进入第 7 步流程，虚构了 17 组数字（0027 工号、N 加 1 九个月、B2-117 车位、HR BP 姓李、七年零四个月、十一万二千公里、白色胎、洗碗机四十分钟……）交付。**这是 skill 失败，不是用户素材失败**。本次修复后，该路径被硬约束在第零关阻断。

## 致命自检（最后一遍）

逐句问：**这句话能不能改成一个数字，或者一个动作？**

能 → 改。
不能 → 它可能是全文允许存在的那一句自陈，留下。但全文这样的句子不许超过 3 句。

## 最后一问

念一遍。如果任何一句读起来像"作者在告诉你他有多难过"，删掉。

这套文体的全部力量在于：**作者从头到尾没说过自己难过，读者却难过了。**
