# 交稿前自检表

任何一项不过 → 回去改，不要交稿。

## 硬性计数

| # | 检查项 | 标准 |
|---|--------|------|
| 1 | 全文数字总数 | ≥ 15 个可测量的数字（金额/天数/人数/秒数/距离/温度） |
| 2 | 程度副词 | 0 个（非常/无比/深深/格外/极其/特别/十分） |
| 3 | 情绪形容词直述 | 0 处（"我很难过""我很爱她""我很痛苦"） |
| 4 | 感叹号 / 省略号 / 破折号 / 引号 | 各 0 个 |
| 5 | 排比句 | 0 处 |
| 6 | 反问句 | 0 处 |
| 7 | 比喻 | ≤ 2 处，且必须是名词性比喻 |
| 8 | 「我说好」类顺从句 | ≥ 5 次 |
| 9 | 「我沉默了 / 我没有说 / 我也没有问」类隐瞒句 | ≥ 4 次 |
| 10 | 打破节拍的那一句 | 恰好 1 次，且在全文 80% 位置 |
| 11 | 服务者复调段落 | ≥ 3 段，每 1500 字至少 1 段 |
| 12 | 物件 callback | ≥ 1 组（中段慢写 + 结尾拆开） |
| 13 | 闭环句 | 恰好 3 次，量级逐次放大 |
| 14 | 结尾遗留物清单 | ≥ 5 件，降序排列 |
| 15 | 结尾的直接提问 | 恰好 1 个，且不回答 |

## 结构检查

- [ ] 第一句是不是一个重量/长度/温度/价格？
- [ ] 前两句是不是构成一组量级悬殊的对句？
- [ ] 第一幕结尾有没有把结局交出去？
- [ ] 起源段是不是一个很小、很早、失败了的动作？
- [ ] 高潮段的字数是不是全文最短的实质段落？
- [ ] 高潮有没有用秒数替代情绪？
- [ ] 称呼有没有在关键时刻切换回原名？
- [ ] 结尾有没有从最小量级拉到最大量级？

## 致命自检（最后一遍）

逐句问：**这句话能不能改成一个数字，或者一个动作？**

能 → 改。
不能 → 它可能是全文允许存在的那一句自陈，留下。但全文这样的句子不许超过 3 句。

## 最后一问

念一遍。如果任何一句读起来像"作者在告诉你他有多难过"，删掉。

这套文体的全部力量在于：**作者从头到尾没说过自己难过，读者却难过了。**
