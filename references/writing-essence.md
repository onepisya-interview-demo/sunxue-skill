# 写作总纲 · 心法 / 闸门 / 公式 / 镜像

> 本文件是写作引擎的"心法层"——技法之上、规则之下的"为什么这样做"。SKILL.md 在 4 模式入口处只放极简卡片,完整论述见本文件。

---

> **目录**：1 第一原则：温度计归零 · 2 第零关：素材配不配 · 3 仿写公式 · 4 镜像识别

## 1. 第一原则:温度计归零(来自 gehao628 sun-writing)

**凡是可以写成情绪的地方,一律改写成一个可测量的事实。** 越是情绪最强的地方,写得越冷。情绪是证据的利息;本金是动作、数字、物件、空间——你只出示本金,利息由读者自己结算。

> 温度计归零。你的任务不是表达感受,而是**出庭作证**:每一句话都必须是"看得见、摸得着、量得出、查得到"的东西。

| 你想写的情绪 | 改写成 |
|---|---|
| 我很难过 | 「我把手放在胸口,数了一下。心跳很稳。一分钟六十几下,和平时没有区别。」 |
| 她很浪费钱 | 「那一层包下来,三十天,一百万美元。她住了八天就走了。」 |
| 我配不上她 | 「我买了一件羽绒服,一百五十块。我犹豫了三天。同一年她拍了一部一亿五千万的电影。」 |
| 我们的努力都白费了 | 「A330 是按两百人设计的,我们只有三十个人,太轻了,起飞的配平不对。所以每次都要多加油,加到够重为止。到了地方,多加的那些又不能留着,得放掉。」 |

判断一个句子是否合格:想象你把这句话念给一个与故事无关的陌生人听,他能否复述出一个**画面**。能,留下;不能(只复述出一个情绪词),删。

## 2. 第零关:先判断这个素材配不配(来自 gehao628 sun-writing)

**这套写法是用来压住巨大东西的。** 素材本身不够重,写出来不是克制,是矫情——等于为一件小事架大炮。动笔前过两个闸门,**至少满足一个**:

- **条件 A · 巨大量级差** —— 素材里存在两个量级悬殊的可测量事实。原文是「三点五微克 / 两点五吨」「一千块的宿舍 / 一亿五千万的电影」。
- **条件 B · 不可逆的失去** —— 有一样东西永远回不来了。原文的内核是「她走了,再也没有了」——所以结尾那份遗留物清单才有重量。

**活样本 1 · 条件 A**(开篇第 2-3 行):3.5 micrograms(一粒卵子)vs 2.5 tons(5000 万美元现金)—— 12 个数量级被压成两行短句,第三行才允许出现人。
**活样本 2 · 条件 B**(包下整层一节):那一层包下来,三十天,一百万美元,为了她的隐私。她住了八天就走了。剩下二十二天空房,三十个工人按"登记上写着有人"的标准把毛巾换完——**八个字的失去 + 二十二天空房**。

**两条都不满足 → 不要写,告诉用户换素材。**

| 素材 | 判定 | 为什么 |
|---|---|---|
| 被客户放鸽子等两小时 | ❌ | 损失只有一个下午,后果是"改天再约"。没有失去,账单式收尾就是一堆废话 |
| 今天上班迟到了 | ❌ | 同上 |
| 把开了五年的公司注销了 | ✅ | 有量级(注册资本、年头、人数),有不可逆 |
| 在一家公司干了八年然后被裁 | ✅ | 有量级(八年、工牌、门禁卡),有不可逆 |
| 送走养了十二年的狗 | ✅ | 条件 B 满分 |
| 还完最后一期房贷 | ✅ | 条件 A 满分(三十年、几百万、每月几千) |
| 室友搬走 | ❌ | 没有量级差,没有不可逆 |
| 考了一次没过的考试 | ❌ | 可以重考,B 不成立 |

**另外**:素材必须来自真实经历,用户要能提供真实细节。编出来的细节会露馅——原文里"胶带买了三十卷后来又补了二十卷""下午三点以后贴的最容易掉,因为那时候玻璃最烫"之所以有力量,是因为那是真的发生过的。

### 第零关 · 执行硬约束(v1.1.0 增补)

**本节是闸门本身,不是建议项。违反任一条都算 skill 失败。**

- **判定素材是否充分**——用户原始输入 + 任何补充回答里,**至少要出现**以下其中之一:① 一个可测量的数字(天数 / 金额 / 人数 / 日期 / 距离 / 秒数)② 一个具体真实细节(人名 / 地点 / 物件 / 岗位 / 部门编号)。
- **不充分 → 唯一合法动作是 `ask_user_question`**——必须用以下七个字段向用户索要真实细节,**不允许**进入第 1 步写作流程:
  1. 在这家公司待了多久(司龄)
  2. 通知 / 谈话是哪天、以什么形式发生
  3. 补偿方案是什么(N / N+1 / 2N、几个月、按什么基数)
  4. 离开时带走或留下的一两件实物(物件原型)
  5. 当时在场的边缘人物(前台 / HR / 行政 / 保安 / 保洁 / 物业……具体到谁)
  6. 最后离开那栋楼的具体物理动作(电梯楼层 / 停车场 / 班车 / 出租车)
  7. 这件事是否允许虚构细节(如果允许,必须给出"哪些是真 / 哪些可编"的边界)
- **用户跳过任何字段 = 该字段不写进正文**。**不允许用编造填位**——宁可让该处留白、用模糊语("几十天""几号""某个工位"),也不允许出现具体但虚构的数字。
- **充分 → 才进入第 1 步(找两个重量)**,进入后必须建立**白名单**:本轮所有用到的数字与人名 / 物件 / 地点,**仅**从用户输入和回答里抽取。范本里的数字(3.5 微克 / 2.5 吨 / B2-117 / 11.2 万公里 / 三十卷胶带)一律**不得**当作模板套用到新稿——这是另一类偷懒。
- **白名单会在第 7 步门禁回环里被自动校验**(见 `references/writing-checklist.md` 第 16 项"虚构红线")。校验不通过 → 整稿作废 → 回第零关补素材。

## 3. 仿写公式(来自 bayshier)

孙学已从文风演变为公共梗。处理仿写与对照分析时:

**仿写公式 = 原文句式 + 新主语 + 最高潮处收手。**
- 「我的女友景甜」→「我的男友孙哥」(玉伯式五字仿写)
- 「一座失去皇后的凡尔赛宫」→ 换两个名词即成新句
- 仿写的笑点在省略号里,补全即死亡;**只借句式,不借他人真实隐私。**

**玩梗的安全边界**(与判断引擎的禁用清单一脉相承):
- 不拿真实私生活作梗
- 不拿弱势群体作梗
- 仿写对象必须是已经公开过的"梗"或泛化场景,不针对具体无辜个人

## 4. 镜像识别(来自 bayshier)

当事件另一方用排比、宣言、全称时间("过去、现在、未来")回应时,那是演说体;孙学是证词体。**赢掌声用演说体,留回声用证词体。** 帮用户选边或混用时先问清目的。

**演说体 vs 证词体**(精简对照):

| 维度 | 演说体 | 证词体(孙学) |
|---|---|---|
| 目的 | 赢掌声 | 留回声 |
| 句式 | 排比、宣言、反问 | 单句成段、短句、数字 |
| 时间 | 全称时间(过去/现在/未来) | 锚定年份/秒数 |
| 形容词 | 多 | 0 |
| 比喻 | 多 | ≤ 2 处名词性 |
| 称呼 | 抽象化(同胞/朋友们) | 具体化(本名/妈妈/她) |
| 收尾 | 升华 | 落空 |

对照标本见 `references/x-field-notes.md`(景甜镜像回应文本)。
