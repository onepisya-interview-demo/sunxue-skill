## 五幕骨架

| 幕 | 页 | 功能 | 关键动作 |
|---|---|---|---|
| Ⅰ | 1–2 | 度量衡开场 + 结局前置 | 3.5 微克 vs 2.5 吨；空置的整层楼与空停的飞机；「第八天她打了那个电话。之后没有人再见过她。」 |
| Ⅱ | 2–3 | 起源神话 | 2007 年未被通过的好友申请；十九年的隐性刻度；「十九年后，名单上加了我。」 |
| Ⅲ | 3–11 | 主体推进 | 香蕉→包场→磨指甲→四十几页调查→特纳里费→马尔代夫→求婚→香港→彩礼→失联前夜 |
| Ⅳ | 12–13 | 高潮（删掉高潮） | 五千万 → Claude → 十一秒 → 心跳很稳 |
| Ⅴ | 13–15 | 账单式收尾 | 七件遗留物降序 → 一个不回答的问题 → 一百万人 |

## 每一幕的机械做法

### 第 Ⅰ 幕：怎么起

1. 第一句独占一行，只有一个重量：「一颗卵子的重量，三点五微克。」
2. 第二句给出量级悬殊的对句，并在第三句完成交易定义：「她向我要的是后者，抵押的是前者。」
3. 立刻插入第一段服务者复调（墨西哥清洁工打扫空房）。
4. 第一次出现闭环句：「什么都不发生。」
5. 幕尾交出结局。

### 第 Ⅱ 幕：起源必须小、早、失败

- 小：一条好友申请
- 早：2007 年
- 失败：她没有通过
- 后果：这个失败变成一生的刻度盘（「到了什么程度，她会通过。第一个十亿的时候我想过，一百亿的时候我想过。」）
- 留一个可携带的物件：那张糊掉的 QQ 图片，每换设备都导过去
- 幕尾一句收束：「十九年后，名单上加了我。」

同幕内完成第一次量级对照：150 元羽绒服犹豫三天 ↔ 同年 1.5 亿的《战国》。
并在此埋下第二次闭环句：《战国》众星「来都来了，总得发生些什么，但是什么都没有发生」。

### 第 Ⅲ 幕：双线节拍 + 螺旋上升

顺从线（我说好）：香蕉 → 包场清人 → 出发特纳里费 → 改口叫妈妈 → 3000 万彩礼 → 五张卡轮转 → 香港买房写她名字。
每一次答应都不解释、不还价。

隐瞒线（我没有说）：她讲的和调查不一样（我没有说）→ 她说不如德令哈而我是青海人（我没有说）→ 她问那张照片是谁（我沉默了）→ 她两次问能不能来北京（我沉默了）。

夹在中间的三处关键装置：
1. **唯一的温柔**：磨指甲一小时，三个面，「最后一面不要来回蹭，要顺着一个方向」，预言台词「要是以后我不在了，就再没有人给你抛指甲了」。
2. **信任的双句**：「我全部相信她说的。／那份东西我留着，一直留到现在。／但是我一个字也不信。」
3. **服从性测试**：「我在想，你会不会有一次说不。／我说不会。／她说，那就没意思了。」

服务者复调在本幕出现三次：贴胶带的两个女孩、看房视频里的影子、（下一幕的）飞机配平。

### 第 Ⅳ 幕：高潮怎么删

三步反转设计：
1. **排除经济动机**——「我用 Claude Code 读 API 把所有现金资产跑了一遍，结论是对我不会有任何影响。我又核了一遍。」
2. **引入外部裁决**——「Claude 说，不要把这五千万美元给她。／我问，她不再爱我了吗？／Claude 说，对于爱情，我不关心，也不理解。但是你不能把这五千万美元给她。」
3. **自我剖白（全文唯一允许的心理解释）**——「我从来没有拒绝过她，不是慷慨，是害怕。害怕下一秒的答案。而现在有人替我说了。」

第二重反转：「让我毛骨悚然的不是它聪明，是 Claude 一点犹豫都没有。／它不为难。／我当时想，这大概是更高的一种东西。人做不到这样。」

分手本体只有三行，用秒数替代情绪，并把称呼切回原名：
> 我数了一下，十一秒。
> 她说，行。
> 她说，我知道了。

紧接反高潮生理动作：手按胸口数心跳，「心跳很稳」「一分钟六十几下，和平时没有区别」「我想，原来是这样」。
幕尾一句定全文主题：「我没有哭。我一直在等我哭。」

**注意：这篇文章的真正主题不是失去她，是发现自己失去了感受能力。**

### 第 Ⅴ 幕：账单收尾

七件遗留物，降序（大→小、公→私）：
1. 特纳里费整块朝大西洋的落地玻璃要换（胶带在他们走后又贴了几天，没人通知不用贴了）
2. 飞机燃油配平：A330 按两百人设计，只坐三十人太轻，每次多加油，到地方再放掉。「我说，每次都这样？／他说，每次都这样。」
3. 洛杉矶诊所寄回的一箱促排针，要冷藏的，一支没拆
4. 代孕机构二十万美元定金，不退；档案里有照片，他没看过
5. 2007 年那张照片：设备像素越来越高，这张图越来越糊，放大也找不出不同，「因为那张照片本来就看不清」
6. 磨甲工具：磨两下不对，忘了是顺哪个方向，放回去了。「我的指甲现在还是磨人的。」
7. 日历提醒「预产期前三个月，准备房间」——「我把它划掉了。」

然后是唯一的直接提问，不回答：「如果那天我给了，她会留下来吗。」

最后闭环句第三次出现，量级拉到最大：
> 一百万人像潮水一样涌来，烟花结束，一百万人退去。
> 一百万人。
> 每年都是这样。
> 凌晨三点的香港，
> 什么都没有发生。

## 可直接复用的句式

- 「我说好。」
- 「我沉默了。」
- 「我没有说。」
- 「我也没有问。」
- 「我把它放回去了。」
- 「我把它划掉了。」
- 「每次都这样？／每次都这样。」
- 「我全部相信她说的。／但是我一个字也不信。」
- 「她知道那两个女孩叫什么。我不知道。」
- 「我数了一下，X 秒。」
- 「和平时没有区别。」
- 「我想，原来是这样。」
- 「我一直在等我 XX。」
- 「什么都没有发生。」
