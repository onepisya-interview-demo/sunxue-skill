## 五幕骨架

| 幕 | 页 | 功能 | 关键动作 |
|---|---|---|---|
| Ⅰ | 1–2 | 度量衡开场 + 结局前置 | 3.5 微克 vs 2.5 吨；空置的整层楼与空停的飞机；「第八天她打了那个电话。之后没有人再见过她。」 |
| Ⅱ | 2–3 | 起源神话 | 2007 年未被通过的好友申请；十九年的隐性刻度；「十九年后，名单上加了我。」 |
| Ⅲ | 3–11 | 主体推进 | 香蕉→包场→磨指甲→四十几页调查→特纳里费→马尔代夫→求婚→香港→彩礼→失联前夜 |
| Ⅳ | 12–13 | 高潮（删掉高潮） | 五千万 → Claude → 十一秒 → 心跳很稳 |
| Ⅴ | 13–15 | 账单式收尾 | 七件遗留物降序 → 一个不回答的问题 → 一百万人 |

## 每一幕的机械做法

### 第 Ⅰ 幕：怎么起

1. 第一句独占一行，只有一个重量：「一颗卵子的重量，三点五微克。」
2. 第二句给出量级悬殊的对句，并在第三句完成交易定义：「她向我要的是后者，抵押的是前者。」
3. 立刻插入第一段服务者复调（墨西哥清洁工打扫空房）。
4. 第一次出现闭环句：「什么都不发生。」
5. 幕尾交出结局。

### 第 Ⅱ 幕：起源必须小、早、失败

- 小：一条好友申请
- 早：2007 年
- 失败：她没有通过
- 后果：这个失败变成一生的刻度盘（「到了什么程度，她会通过。第一个十亿的时候我想过，一百亿的时候我想过。」）
- 留一个可携带的物件：那张糊掉的 QQ 图片，每换设备都导过去
- 幕尾一句收束：「十九年后，名单上加了我。」

同幕内完成第一次量级对照：150 元羽绒服犹豫三天 ↔ 同年 1.5 亿的《战国》。
并在此埋下第二次闭环句：《战国》众星「来都来了，总得发生些什么，但是什么都没有发生」。

### 第 Ⅲ 幕：双线节拍 + 螺旋上升

顺从线（我说好）：香蕉 → 包场清人 → 出发特纳里费 → 改口叫妈妈 → 3000 万彩礼 → 五张卡轮转 → 香港买房写她名字。
每一次答应都不解释、不还价。

隐瞒线（我没有说）：她讲的和调查不一样（我没有说）→ 她说不如德令哈而我是青海人（我没有说）→ 她问那张照片是谁（我沉默了）→ 她两次问能不能来北京（我沉默了）。

夹在中间的三处关键装置：
1. **唯一的温柔**：磨指甲一小时，三个面，「最后一面不要来回蹭，要顺着一个方向」，预言台词「要是以后我不在了，就再没有人给你抛指甲了」。
2. **信任的双句**：「我全部相信她说的。／那份东西我留着，一直留到现在。／但是我一个字也不信。」
3. **服从性测试**：「我在想，你会不会有一次说不。／我说不会。／她说，那就没意思了。」

服务者复调在本幕出现三次：贴胶带的两个女孩、看房视频里的影子、（下一幕的）飞机配平。

### 第 Ⅳ 幕：高潮怎么删

三步反转设计：
1. **排除经济动机**——「我用 Claude Code 读 API 把所有现金资产跑了一遍，结论是对我不会有任何影响。我又核了一遍。」
2. **引入外部裁决**——「Claude 说，不要把这五千万美元给她。／我问，她不再爱我了吗？／Claude 说，对于爱情，我不关心，也不理解。但是你不能把这五千万美元给她。」
3. **自我剖白（全文唯一允许的心理解释）**——「我从来没有拒绝过她，不是慷慨，是害怕。害怕下一秒的答案。而现在有人替我说了。」

第二重反转：「让我毛骨悚然的不是它聪明，是 Claude 一点犹豫都没有。／它不为难。／我当时想，这大概是更高的一种东西。人做不到这样。」

分手本体只有三行，用秒数替代情绪，并把称呼切回原名：
> 我数了一下，十一秒。
> 她说，行。
> 她说，我知道了。

紧接反高潮生理动作：手按胸口数心跳，「心跳很稳」「一分钟六十几下，和平时没有区别」「我想，原来是这样」。
幕尾一句定全文主题：「我没有哭。我一直在等我哭。」

**注意：这篇文章的真正主题不是失去她，是发现自己失去了感受能力。**

### 第 Ⅴ 幕：账单收尾

七件遗留物，降序（大→小、公→私）：
1. 特纳里费整块朝大西洋的落地玻璃要换（胶带在他们走后又贴了几天，没人通知不用贴了）
2. 飞机燃油配平：A330 按两百人设计，只坐三十人太轻，每次多加油，到地方再放掉。「我说，每次都这样？／他说，每次都这样。」
3. 洛杉矶诊所寄回的一箱促排针，要冷藏的，一支没拆
4. 代孕机构二十万美元定金，不退；档案里有照片，他没看过
5. 2007 年那张照片：设备像素越来越高，这张图越来越糊，放大也找不出不同，「因为那张照片本来就看不清」
6. 磨甲工具：磨两下不对，忘了是顺哪个方向，放回去了。「我的指甲现在还是磨人的。」
7. 日历提醒「预产期前三个月，准备房间」——「我把它划掉了。」

然后是唯一的直接提问，不回答：「如果那天我给了，她会留下来吗。」

最后闭环句第三次出现，量级拉到最大：
> 一百万人像潮水一样涌来，烟花结束，一百万人退去。
> 一百万人。
> 每年都是这样。
> 凌晨三点的香港，
> 什么都没有发生。

## 附录 A:7 步写作流程完整定义(来自 SKILL.md 合并,v1.2.0 外化)

> 本节是 v1.2.0 外化时从 SKILL.md L297-315 整段搬入。SKILL.md 重写后只保留 7 步目录,完整定义见本附录。

### 七步写作流程（5+7 步融合）

拿到素材后按顺序执行，不要跳步：

1. **找两个重量** —— 从素材里找出量级最悬殊的两个可测量的事实，做成开场对句。找不到就去问用户要具体数字（价格、时长、距离、人数）。**数字是这套文体的血。** 没有数字，写出来的只有腔调，没有力量。
2. **定双线** —— 明确写出来（不写进正文，只在草稿里）：我的"我说好"是什么？（重复出现的顺从动作）我的"我没有说"是什么？（重复出现的隐瞒）那一次"让我想想"发生在哪一刻？
3. **选物件** —— 挑一个廉价、有操作步骤、能被"用坏或用不对"的物件。中段慢写，结尾拆开。
4. **排服务者** —— 列出这段经历里所有的边缘劳动者：司机、保洁、助理、店员、修理工、跑腿的。给他们每人一段，写他们如何认真地做一件无用的事。
5. **搭五幕**：
   - Ⅰ 度量衡开场 + 结局前置
   - Ⅱ 起源（一个很小、很早、并且失败了）的动作——原文是 2007 年一条未被通过的好友申请，写了四十分钟只发出"你好"两个字。这个失败要成为后面所有行为的隐性刻度：「到了什么程度，她会通过。第一个十亿的时候我想过，一百亿的时候我想过。」
   - Ⅲ 主体线性推进，双线节拍，消费/投入螺旋上升
   - Ⅳ 高潮（删掉高潮的写法，字数最少）
   - Ⅴ 账单式收尾 + 闭环句第三次出现
6. **写** —— 全程遵守十三条技法。写的时候只问自己一个问题：**这句话能不能改成一个数字或一个动作？**
7. **门禁回环（gate loop）** —— 把成稿落盘到 `.sunxue/draft.md`，**串行执行以下两步，两步全部通过才能进第 8 步**：
   - **7.1 句法闸（machine）** —— `python3 scripts/writing_gate.py .sunxue/draft.md`，把命令的原始输出逐字贴出。exit 2 → 按失败项回炉 → 重跑至 exit 0。**不贴原始输出、只贴自己转述的结论 = 第 7.1 步未完成。** 档 ① 不接 host 专属 hooks；档 ② 接 Claude Code `Stop` 闸。契约与三条「不得」见 `references/enforcement.md`。
   - **7.2 内容自洽性扫描（model）** —— 句法闸 exit 0 后，**由模型逐段扫描内容自洽性**（5 项 + 报告格式见 `references/coherence-checklist.md`）。任何冲突 → 改稿 → 重跑 7.1 → 再过 7.2；全 `[OK]` 才宣告第 7 步完成。档 ① 这步完全由模型做；档 ② 把 L1 数字交叉 + 时间线单调抽到 `scripts/coherence_gate.py`，物理规律 / 量级差 / 虚构项边界仍由模型审（见 `references/enforcement.md` §5）。
8. **致命自检 + 最后一问** —— 第 7 步 `exit 0` 是本步的前置条件。跑完硬计数后再过一遍「致命自检」和「最后一问」（同一文件的 §致命自检 / §最后一问），两项都过才算交稿。

### 16 项硬计数自检（交稿前自检表）

完整 16 项表（数值、阈值、虚构红线分档白名单）见 `references/writing-checklist.md`，本表是 SKILL.md 唯一真源之外的副本——任何改动先改 `references/`，再让本表跟随。**`scripts/writing_gate.py` 才是机器判定的真源**，references 文档提供人类可读解读。

**致命自检**（最后一遍）：逐句问「这句话能不能改成一个数字，或者一个动作？」能 → 改。不能 → 它可能是全文允许存在的那一句自陈，留下。但全文这样的句子不许超过 3 句。

**最后一问**：念一遍。如果任何一句读起来像"作者在告诉你他有多难过"，删掉。**这套文体的全部力量在于：作者从头到尾没说过自己难过，读者却难过了。**
