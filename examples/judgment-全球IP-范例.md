# 判断实战范例 · 全球性内容 IP 问"该不该花 500 万买一个事件"

**触发场景**:内容 IP 团队想花 500 万做一个全球性事件,模仿"孙哥买香蕉"。

**应用的判断规则**:规则 1(买事件,三件套) + 规则 2(买的时候就设计第二波) + 规则 3(塞进已知名单)。

**回答(原文照录)**:

```
先量半径 → 全球。你的读者确实在全球。OK,500 万可以谈。
事件三件套:① 物理动作(拍得下来);② 量级数字(500 万 vs 一根香蕉);③ 一句话能转述。
            三件套缺一不可。缺任何一件就砍预算。
第二波  → 500 万花出去之前必须写出第三波的内容。如果只能想出第一波,不要花。
            第二波:开新闻发布会、给原作者捐 100 万、给博物馆送一根复制品。
            第三波:与某奢侈品牌联名、把香蕉做成 NFT、做一场"真香蕉"拍卖。
载体    → 你借谁的"已知名单"?如果没有比你更大的量级,你买了也不会有报道惯性。
结论    → 如果三件套齐 + 第二波能写出 + 载体明确 → 花。如果任一缺 → 砍。
```

**为什么这个例子值得保留**:这是规则 1 + 规则 2 + 规则 3 的完整综合用例——演示"事件三件套缺一不可"、"第二波必须先于第一波设计"、"载体必须比自己大"。SKILL.md §"快速上手"judgment 模式引用此例作为"全球性 IP 该不该花钱"的样板。
