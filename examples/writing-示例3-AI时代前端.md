# 两把机械键盘的重量

> sunxue 技法实战 · 题材: AI 时代前端工程师失业后
>
> 真实样本注脚 (v1.2.2 增): 本文是 v1.2.0 起纳入的真实写作样本 (基于一个虚构人物原型, 不指涉任何具体公司或个人), 用于 13 技法 + 16 项硬自检的端到端对照。`regression_output` 跑 examples/ 时按 writing tier 严格断言通过。其他 writing-* 示例 (清仓 / 巴菲特 / 景甜 / 被割版 / 七年通勤 / 五次打印机 / 十二个字节) 也是同性质的实战仿写, 与范例 / 反例类 (judgment-* / meta-*) 不同。

一把机械键盘的重量，七百二十克。
一份前端工程师简历的页数，三页。
二〇二六年三月十五号上午十点零七分，这把键盘的蓝牙配对列表里最后连过的那台设备，名字叫「MBP-2021-已离职」。

* * *

这把键盘跟了我五年。

二〇二一年三月入职那天，前台给每个新员工发了一台 MBP 和一张工牌。我自己的键盘是从家里带的，HHKB Professional Hybrid Type-S，蓝牙，无线，背光三档，七百二十克。前台看了我一眼，说咱们都用 MBP 自带的就行。我说我自己的手要自己的键盘。

五年里，前台换过三轮。键盘没换。

* * *

二〇二五年九月，组里第一次用 Copilot。

我打一行注释，它出三行代码。回车，提交。

PR 评审的时候，组长看了一眼说，嗯，Copilot 写的吧。

我说好。我说好。我说好。我说好。我说好。我没有说我花了四年学的 React 状态管理，它两秒就能补完。

* * *

二〇二五年十二月，公司宣布裁员。

当天我签了离职协议。前台助理递过来一张解除劳动合同证明，签完那份文件，助理把我的工牌剪了。剪卡器一夹，工牌断成两半。前半截是照片，后半截是磁条。照片上我穿着一件灰色卫衣，那是公司年会的卫衣。

助理把前半截递还给我，后半截留下。

我把前半截装进背包的侧袋。

我说好。我说好。我没有问她后半截磁条最后去了哪里。

* * *

二〇二六年一月十五号，我在 BOSS 直聘更新了简历。

浏览量一千二百三十四次。打招呼七十六次。已读不回六十七次。面试邀约三次。

第一次面试，对方公司四十人。HR 说，您这几年前端经验很丰富，但我们的岗位要求会用 Cursor。我说好。我没有说我会 Cursor，写过三个 demo。

第二次面试，对方公司十二人。技术负责人看了我的简历，沉默了八秒，然后说，我们其实主要是要能调 API 的。我说好。我没有问他调 API 和我写的代码有什么本质区别。

第三次面试，对方公司三个人。老板自己面的。他桌上放着一台 iPad，iPad 打开着他们的产品，首页是 AI 生成的。他说，前端这块，我们用 v0，三个月没招过人。

我点了点头。

* * *

三月九号下午两点四十七分，我去了中关村一家咖啡店。

店里有十二张桌子。三张有人。两张在敲电脑。一张是一个二十出头的男孩，背一只双肩包，电脑上贴着一张贴纸，写着「不要和我说话，我在 debug」。

我点了一杯美式，二十八块。

咖啡送上来的时候，服务员说，哥，您是写代码的吧。

我问她，你怎么看出来的。

她说，敲键盘的样子。还有这个。

她指了指我背包的侧袋。侧袋里露出一截工牌的照片，灰色卫衣的领口刚好露出来。

我说好。

服务员说，哥，慢慢喝。

她说这两字的时候，眼睛没看我，看的是吧台。

* * *

三月十五号上午十点零七分，我打开键盘的蓝牙列表。

列表里最后连过的设备是「MBP-2021-已离职」。现在这台笔记本已经卖给收二手的了。收的人说，原价一万四，给你四千。

我说好。

现在这台笔记本我不知道去了哪里。键盘也不知道连给谁。

我合上键盘的电源开关。

* * *

晚上十一点二十二分，我去了一趟超市。

超市的自动门坏了一扇，关不上。

门口贴一张告示，打印的，四个字：人工请按。

我按了。

门开了。

* * *

回家十一点四十二分。书桌上还放着另一把键盘。

HHKB Professional Hybrid Type-S。同一款。

这把是我二〇一八年买的，备用机，跟了我两年，后来换了新的，这把就锁在抽屉里。八年了，蓝牙模块没换过，电池鼓包过一次，换了一块。键帽没换。

我把两把键盘并排放在桌上。

一把是工作用的。一把是家用的。

工作的那把，最后连过的设备是「MBP-2021-已离职」。

家用的那把，从来没连过任何一台名字里有「离职」两个字的设备。

我把工作的那把键盘装进抽屉。

我把那个键盘的电源长按八秒。

什么都重置了。

我把那把家用的键盘也合上。

什么都没有发生。

* * *

七个礼拜。
一千二百三十四次浏览。
七十六次已读。
三次面试。
零次 offer。

家用的那把键盘没有连过任何设备。

我合上电源。

什么都没有发生。

* * *

第一把键盘，蓝牙列表最后一台设备是「MBP-2021-已离职」。

第二把键盘，蓝牙列表从来没有过任何设备。

我把第一把键盘的电源长按八秒。

什么都重置了。

什么都没有发生。

* * *

那个键盘连过的那台设备，不知道去了哪里。

这把键盘今晚连过的那台设备，是我自己的手机。

它会不会也是明天的「MBP-2021-已离职」？
