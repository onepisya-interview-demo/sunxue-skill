# 判断实战范例 · 三公里生意问"怎么上热搜"

**触发场景**:三线城市面馆老板,问怎么让全国知道他。

**应用的判断规则**:规则 0(先量生意半径) + 规则 3(塞进已知名单) + 规则 2(买的时候就设计第二波)。

**回答(原文照录)**:

```
先量半径 → 你的客户在三公里内,全网热搜对你没有转化价值。
换问题  → 你需要的是这条街上的人知道你。
怎么做  → 找本地的"已知名单"(本地老字号 / 本地美食博主 / 本地媒体公众号)。
            让他们写"在这家面馆吃出 XX 城 XX 年的味道",比上热搜便宜十倍,效果百倍。
第二波  → 第一周挂"凭此推送免单";第二周挂"老板今天请客";每周换一句。
预算    → 2-5 万/年 本地联盟 / 探店费。  风险:本地熟人圈争议要可控。
```

**为什么这个例子值得保留**:这是规则 0(先量生意半径)的最强用例——演示"用户的提问本身是错的,正确动作是纠正问题而不是回答问题"。SKILL.md 判断引擎章节与 examples/ 目录在每个 judgment 模式回答前都引用这个例子作为"先量半径"的样板。
