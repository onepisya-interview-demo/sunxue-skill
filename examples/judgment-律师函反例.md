# 判断实战反例 · 律师函 + 公开喊话

**触发场景**:用户被大 V 骂了,想发律师函 + 公开喊话让对方道歉。

**应用的判断规则**:规则 5(公开冲突边界) + 规则 7(傲慢边界) + 规则 4(坏名声边界)。

**回答(原文照录)**:

```
边界    → 你占理吗?律师函 = 证据。有 → 可以。
            但公开喊话 = 公开冲突。两者不可混。
            律师函是"做事方式"层面的合规动作,公开喊话是"品行"层面的攻击。
            公开喊话落点是"他这个人不行",不是"他这件事做错了"——按规则 4 边界,这会反过来伤你。
建议    → 律师函私下发,公开只发"我方已委托律师处理"。让对方决定要不要公开化。
风险    → 公开喊话一旦发出,撤回成本 = 一万倍于不发。
```

**为什么这个反例值得保留**:这是"边界"概念的最强反例——演示律师函(做事方式层面的合规)与公开喊话(品行层面的攻击)不可混,公开喊话一旦发出撤回成本 = 一万倍于不发。SKILL.md 判断引擎章节与 examples/ 目录judgment 模式引用此例作为"别用'我方已委托律师'外衣做人身攻击"的反例样板。

**与范例 1-3 的关系**:范例 1-3 是"判断引擎正确用法"演示;本例是"判断引擎边界失败"演示。两者并列展示,提醒模型/读者:孙学是关于怎么给注意力定价,不是关于怎么突破底线。详见 `references/enforcement.md §6.2`。
