# 判断实战范例 · 行业级 B 端供应商问"要不要蹭一个争议事件"

**触发场景**:B 端供应商看到竞品被曝数据造假,问要不要写檄文蹭一下。

**应用的判断规则**:规则 4(坏名声比没名声好,有边界) + 规则 5(公开冲突是最便宜的传播,有边界) + 规则 7(傲慢是最先被清算的资产)。

**回答(原文照录)**:

```
先量半径 → 你在行业里。你的读者是同行 + 客户 + 投资圈。这个量级允许买事件。
边界    → 你占理吗(你们有数据对比)?有证据吗(第三方审计 / 用户证言)?承受得起关系破裂吗(这个客户会失去吗)?
            三条都满足 → 可以打。三条任一不满足 → 沉默。
怎么打  → 写一篇"我们做这件事 5 年没说过的话"——克制、数字、不点名。
            让读者自己得出结论。赢学=克制=让对方自己流血。
第二波  → 3 天后再发一封"给同行的一封信"——把私人攻击升格为行业倡议。
风险    → 如果对方反扑,攻击落在"品行"而非"做事方式"上,你已经输了。退。
```

**为什么这个例子值得保留**:这是规则 4 + 规则 5 边界的最强用例——演示"占理 + 有证据 + 承受得起关系破裂"的三条边界同时满足才打;任一不满足就沉默。SKILL.md 判断引擎章节与 examples/ 目录judgment 模式引用此例作为"边界三问"的样板。
