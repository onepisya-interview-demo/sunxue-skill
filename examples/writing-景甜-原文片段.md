# 景甜原文片段 vs sunxue 仿写

> 本文件是一份"段落级对照样本"。每一段给出：① 一段《My Girlfriend Jing Tian》原文（从 `references/jingtian-essay-7000.md` 精选并译成中文），② 一段按 sunxue 技法 1:1 仿写的段落（题材已替换，但语感结构保留），③ 技法对照表（标注原文与仿写各自用到了 SKILL.md 13 技法中的哪几条）。
> 
> 三段覆盖 sunxue 的三个核心母题：服务者复调、名词句判决、物件 callback。读完这三段，你应该能感受到"语感"和"结构"是分开的——语感可以换题材，结构是固定的。

---

## 段 1 · 服务者复调场景

### 原文（约 230 字）

> 剩下的二十二天里，酒店二十二层的保洁员每天照常上来。我的助理后来跟我讲——她去退房卡那天，在走廊尽头撞上了其中一个：一个推着清洁车的女人，推车在走廊里走得很稳，挨着门牌号一间一间地推开。毛巾叠两次放进浴缸，台面用一块干净的白布擦两遍，被角塞进床沿，枕头拍两下，出来，关门。一整层做完，要两个小时。助理问她，没有人住，为什么还要做。她说，登记上写着有人。助理后来又问了一组上早班的人，回答也差不多。工牌上的名字我没问。

### sunxue 仿写（约 270 字）

店里最晚走的那桌客人，两点四十七分结的账。两个人，坐了四十分钟，点了两杯美式，一份芝士蛋糕。

走后服务台的女孩先收了一次桌。把咖啡杯和盘子端走，抹布在桌面上擦了两下，关掉了那一桌的台灯，就去后厨了。

真正开始彻底擦是清洁工。男的，五十出头，灰色工服，胸前别一只没有照片的工牌。他从最后一桌往前推，一桌一桌：桌面先用干抹布擦一遍，再用湿抹布擦一遍。椅子翻过来在四条腿上各拍一下。地上有纸屑用铲子铲，没有就用拖把拖一下。三十二张桌子，他擦了四十多分钟。

我问他，店已经打烊了，为什么还要一桌一桌都过一遍。

他说，单子上写的。

他没说上面写着。

### 技法对照表

| 技法 | 名 | 原文 | 仿写 |
|:---:|---|:---:|:---:|
| A | 度量衡开场 + 结局前置 | ✓ 22 天 / 2 小时 | ✓ 2:47 收账 / 40+ 分钟擦 32 桌 |
| B | 短段呼吸 | ✓ 单句成段，敲钉节奏 | ✗ 段落略长于原文 |
| C | 数字替代形容词 | ✓ 22, 8, 2 全是数字 | ✗ 用了一些"五十出头""四十多"等模糊量 |
| D | 服务者复调 | ✗ 原文段 3 是"复调"母版，本对照只借结构 | ✓ 清洁工对单子"上面写着"的复刻 |

**结构对位**：原文 22 天 vs 仿写 40+ 分钟——量级差是"22 天无意义工作"对"40 分钟无意义工作"。原文中"登记上写着有人"被仿写为"单子上写的"——都把"系统里有一条记录"翻译成"我必须做这件事"的理由，但都不解释这条记录是谁留下的。原文用"助理问"做转述，仿写用"我问"做在场——同一种"边缘证词"的不同位置。

## 段 2 · 名词句判决

### 原文（约 200 字）

> 一座失去皇后的凡尔赛宫。我突然意识到——景甜喜欢这个。景甜喜欢一个地方因为她而空着。什么都不发生。蒙太奇拉古纳海滩旁边，一架湾流 G700 尴尬地停在范努伊斯机场，机组每天照常报到，三十天里共签到一百九十二次，燃油加了六次，每次加到三吨半，因为油箱不满不能起飞。飞行员每天给酒店前台发一封邮件，问起飞窗口。前台每天回一封：没有。酒店那一层，房间里二十二瓶依云，瓶盖上都没有动过。

### sunxue 仿写（约 360 字）

一张断了靠背的旧龙椅。

父亲走了之后，那张用了二十年的旧沙发，没人再坐。

二〇一一年他单位分的房子，客厅里那张。皮面已经磨出底布，海绵塌下去五个坑。扶手右边那个最深的，是他的手肘。靠背断过一次，他自己修的，用两根木条从背后钉住，钉头露出来一截，划过一次他外孙的手。我妈把木条用砂纸打平了，又用布包了一层。

我爸走后第三天，我妈说，扔了。

我说好。我没有问她要不要把那张沙发上盖一块布。

沙发后来搬到阳台。靠天。下雨没人收。皮面从左下角开始发霉，霉斑每月大一圈，半年后半个坐垫都黑了。我妈每天从它旁边过，扫一次地，没再坐。

一年零三个月后，搬家公司来了两个师傅，问这是谁的。我妈说，死人的。两个师傅对看了一眼，没说话，抬了。

我妈看着他们把沙发抬下楼。抬到一楼拐角的时候，师傅停了，停了三秒，又抬。

那两根木条，后来没人问过。

### 技法对照表

| 技法 | 名 | 原文 | 仿写 |
|:---:|---|:---:|:---:|
| E | 名词句判决 | ✓ A Versailles without its queen | ✓ 一张断了靠背的旧龙椅 |
| F | 空间 / 量级双锚 | ✓ 楼层（22 瓶水）vs 飞机（192 次签到） | ✓ 客厅（5 个坑）vs 阳台（霉斑） |
| G | 物件 callback | ✗ 段 4 是 G700 飞机一次性出场 | ✓ 木条——中段钉钉子，结尾"那两根木条后来没人问过" |

**结构对位**：原文把"凡尔赛宫"（Y）套在"空楼层"（X）上；仿写把"龙椅"（Y）套在"断靠背旧沙发"（X）上。两个比喻都不解释"为什么是皇后/龙椅"——皇后走和龙椅断是不同量级，但都指向"权力的物理位置现在空着/坏着"。原文的 callback 是飞机（一次性），仿写的 callback 是木条（钉 → 包布 → 没人问），把"修理动作"和"无人问"做了 22 年的隐性时间。

## 段 3 · 物件 callback 收束

### 原文（约 240 字）

> 二〇〇七年。当然，那个烧钱的人不是我。屏幕上弹出来一个 QQ 广告弹窗——她是代言人。联想 IBM 的老台式机，屏幕分辨率是糊的，弹窗里的脸看不清。我把图存了下来。从我那间年租一千块的北大宿舍上网，我在校内网（中国的 Facebook）找到她，发了一条好友申请。校内网要写一条留言。我写了删，删了写，四十分钟。最后发出去的是"你好"。她没通过。她大概也没用过校内网。接下来的很多年，每次我做成一件事，我都会问自己同一个问题：到了什么程度，她会通过。第十个亿的时候我想过。第一百个亿的时候我想过。后来我不想了。

### sunxue 仿写（约 400 字）

二〇〇一年画的。

三十厘米见方，水彩纸，颜料是老师给的那套十二色。我画了一棵椰子树，树下画了一个人在走，画完才发现把人画反了。老师帮我擦了，擦了三遍，纸起了毛。我重新画，腿还是反的。老师给了我八十五分。

同一年我的入学学费是九百多块。二十二年后清盘那天的报告上是负数，位数我没记。

二〇一四年公司搬到新办公室。我妈来看的时候发现了那幅画。她说，椰子树下那个人怎么是反的。我说是。她说，那你挂着吧。

我说好。我没有问她记不记得我从三年级以后再没画过画。我没有说那张画在墙上挂了八年。

二〇二二年三月十一号晚上八点零四分，手机弹了一条通知：公司状态变更为「注销」。我划掉了。助理把墙上的合影和奖牌都取下来，装进两个纸箱。

助理问，这幅画取不取。

我说取。

她把画从墙上摘下来。我从她手里接过来，看了两秒。我把它折了一下，塞进我包的外袋里。

三十厘米见方。八十五分。

### 技法对照表

| 技法 | 名 | 原文 | 仿写 |
|:---:|---|:---:|:---:|
| H | 数码物证 | ✓ QQ 弹窗 / 联想 IBM 电脑 / 校内网 | ✓ 手机弹通知 / 划掉 |
| I | 倍率短句 | ✓ 千块宿舍（出处）vs 1.5 亿电影（段 7） | ✓ 九百多块学费 vs 负八位数的清算 |
| J | 闭环句 x N + 收尾落空 | ✓ "她没通过" → "她大概也没用过校内网" → 闭环 | ✗ 仅"三十厘米见方。八十五分"单次闭合 |
| K | 双线节拍引擎 | ✗ 段 6 是起点埋笔，本段暂未激活"我说好" | ✓ 「我说好」+「我没有说」/「我没有问」交互 |

**结构对位**：原文的 QQ 弹窗（2007 年）→ 校内网好友申请（起点）→ 没通过（中段）→ 她大概也没用过校内网（解释落空）。仿写的水彩画（2001 年）→ 老师擦三遍（中段慢写）→ 挂在办公室八年（埋笔）→ 折一下塞进包里（结尾拆开）。两条线都把"廉价 + 早期 + 没修好"的物件放在结尾——物件本身就是结局，不需要再升华。仿写额外激活 K，把"我说好"和"我没有说"做成交替节拍，模拟"清盘最后一晚"那种"在场的顺从 + 不在场的疑问"。

# 怎么用这份对照

**第一步：先读原文**

把三段原文连起来读一遍。不分析、不做笔记，单纯感受"孙宇晨体"的真实语感：每句话很短、每个字都冷、每个数字都像证人作证。读完你应该有一种"被一个完全不在乎你的人讲述了一段非常重的事"的感觉。

**第二步：看仿写**

注意三件事：① **数字怎么换**——22 天换成 40+ 分钟，22 瓶水换成 5 个坑，1000 块宿舍换成 900 多块学费。你换的不是题材，是"量级"——量级差越大，仿写越像。② **物件怎么换**——QQ 弹窗换成水彩画，G700 飞机换成旧沙发，墨西哥女工换成咖啡店清洁工。物件要"廉价 + 有操作步骤 + 能被用坏"，不要换昂贵的物件。③ **语感结构保留**——短段呼吸、数字精确、不解释象征义、不抒情，结构全部保留；只换题材，不换节奏。

**第三步：看技法对照表**

哪些技法是**核心**（原文/仿写都用）：A 度量衡开场、E 名词句判决、F 空间/量级双锚、I 倍率短句、H 数码物证。**这五条是 sunxue 的骨架，每篇必须用。** 哪些是**可选**（只一方用）：B 短段呼吸、C 数字精确、D 服务者复调、G 物件 callback、J 闭环句收尾落空、K 双线节拍。**这六条是肌肉，可多可少，取决于题材。** 哪些是**进阶**（本对照未覆盖）：L 称呼作为情节、M 删掉高潮——这是更高阶的技法，写作 7000 字以上才用得到。

**第四步：自己写**

选一个**"巨大量级差"或"不可逆失去"**的题材，按仿写结构填进去：

1. **找两个重量**——从你的素材里挖出量级最悬殊的两个可测量事实，做成开场对句。
2. **定双线**——草稿里写下你的"我说好"是什么、你的"我没有说"是什么、你的"让我想想"在哪一刻。
3. **选物件**——挑一个廉价 + 有操作步骤 + 能被用坏的物件。中段慢写，结尾拆开。
4. **排服务者**——列出你这段经历里所有的边缘劳动者：清洁工、助理、店员、师傅、跑腿的。给他们每人一段。
5. **搭五幕**——度量衡开场 → 起源（一个很小、很早、并且失败的）动作 → 主体线性推进 → 删掉高潮 → 账单式收尾。
6. **写**——全程问自己一句话："这句话能不能改成一个数字，或一个动作？" 能 → 改。**写完过 `references/writing-checklist.md` 的 15 项硬自检**。

写完回头看这份对照——你应该能用"我把哪几条母题用了 / 哪几条没用到"清楚地复述出你这一篇的技法组合。**这就是 sunxue 的核心：不是模仿孙宇晨的故事，是把"冷处理巨大事物"的方法学到手。**
